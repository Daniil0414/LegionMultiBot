# Legion MultiBot

Готовое приложение для Windows 10/11 x64: игровые окна «Легиона», отдельные профили и управление VPN.

## Установка — три шага

1. [Скачайте LegionMultiBot-windows.zip](https://github.com/Daniil0414/LegionMultiBot/releases/latest/download/LegionMultiBot-windows.zip).
2. Полностью распакуйте архив в отдельную папку.
3. Откройте **Запустить_Мультибот.bat**.

**Отдельно устанавливать Chrome, Python, Node.js или Xray не нужно — всё уже внутри архива.** Приложение использует встроенный Chromium и собственные компоненты. Права администратора для установки не требуются.

В папке один запускатель. Каталог **app** содержит программу и её компоненты; файлы внутри него вручную запускать не нужно.

## Первый запуск

Выберите **«Без VPN»** или **«С VPN»**, создайте профили и выполните вход в свои игровые аккаунты.

Для режима **«С VPN»** добавьте собственную VPN-подписку в настройках приложения. Xray уже включён в архив; отдельно устанавливать Happ или Xray не нужно. Без VPN профили остаются отдельными, но используют обычное подключение компьютера.

## LegionAutoMiner

[LegionAutoMiner](https://github.com/Daniil0414/LegionAutoMiner) включён по умолчанию. Перед первым открытием игрового окна приложение само скачает и установит скрипт. **При каждом запуске окна скрипт обновляется с GitHub.**

Если GitHub временно недоступен, используется ранее сохранённая версия. Для самой первой загрузки нужен интернет. Добавление других скриптов и отключение выбранного доступны через кнопку **«Скрипт бота»**; ручное отключение сохраняется.

## Личные данные

Аккаунтов, cookies, VPN-ключей, подписок и профилей автора в архиве нет. Ваши данные создаются только при использовании программы:

- настройки и скрипты — в папке `app`;
- настройки VPN и журналы — в `app/.vpn_runtime`;
- авторизация отдельных профилей — в `%LOCALAPPDATA%\LegionMultiBot\Bots`.

Не передавайте эти данные вместе с программой. При обновлении сначала закройте приложение и его окна; новую версию распаковывайте отдельно, сохраняя личные настройки локально.

Версии встроенных компонентов указаны в `app/COMPONENTS.json`, лицензии — в `app/licenses` и соответствующих папках компонентов.
