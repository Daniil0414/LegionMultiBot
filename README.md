# Legion MultiBot

Готовое приложение для Windows 10/11 x64: игровые окна «Легиона», отдельные профили и управление VPN.

## Установка — три шага

1. [Скачайте LegionMultiBot-windows.zip](https://github.com/Daniil0414/LegionMultiBot/releases/latest/download/LegionMultiBot-windows.zip).
2. Полностью распакуйте архив в отдельную папку.
3. Откройте **Запустить_Мультибот.bat**.

**Отдельно устанавливать Chrome, Python, Node.js или Xray не нужно — всё уже внутри архива.** Приложение использует встроенный Chromium и собственные компоненты. Права администратора для установки не требуются.

В папке один запускатель. Каталог **app** содержит программу и её компоненты; файлы внутри него вручную запускать не нужно.

## Обновления приложения

Начиная с **v1.1.4**, при запуске приложение в фоне проверяет новые стабильные версии на GitHub. Для новой версии появляется окно **«Обновить и перезапустить» / «Не обновлять»** с описанием изменений. Скачивание показывает прогресс и поддерживает отмену; установщик проверяет SHA-256, дожидается закрытия приложения и запускает обновлённую версию. При ошибке установки выполняется откат. Если GitHub недоступен, программа продолжает работать.

Для первого перехода с v1.1.1 закройте приложение и его окна, скачайте новый архив и распакуйте в ту же папку с заменой файлов программы. В архиве нет ваших аккаунтов и настроек; они сохраняются. Следующие обновления можно устанавливать из окна приложения.

## Первый запуск

В **v1.1.6** кнопка **«⛏ Рой»** показывает встроенную панель управления автошахтой. Панель можно перетаскивать за заголовок внутри сетки; она перемещается и сворачивается вместе с мультиботом. Одна кнопка **«Запустить всех в шахту»** меняется на **«Стоп»** и управляет всеми открытыми окнами. Крестик скрывает панель; кнопка «Рой» возвращает её. Исправлен шлейф при перетаскивании.

Выберите **«Без VPN»** или **«С VPN»**, создайте профили и выполните вход в свои игровые аккаунты.

Панель **«Рой»** появляется автоматически после открытия первого игрового окна. Для команд автошахты доступны задержки **«0 сек»**, **«1–5 сек»** и **«1–10 сек»**; по умолчанию выбрано **«1–5 сек»**. Команды запуска и паузы отправляются последовательно в порядке аккаунтов: первое окно сразу, затем перед каждым следующим окном выбирается новый случайный интервал из выбранного диапазона. Панель показывает ход рассылки. Нажатие «Стоп» отменяет оставшиеся команды запуска и начинает рассылку паузы.

После нажатия **«Войти / Проверить»** окно управления аккаунтами размывается и блокируется на время подготовки. Индикатор показывает **«Проверка VPN»** с текущим сервером, затем **«Открытие браузера»**. Повторное нажатие не создаёт второй запуск. Chrome для входа в Twitch открывается в большой встроенной области мультибота; всплывающие окна авторизации также встраиваются туда. Когда браузер встроен, окно списка аккаунтов закрывается. Кнопка **«Вернуться к сетке»** переносит тот же браузер в ячейку аккаунта, сохраняя профиль и авторизацию. При ошибке блокировка снимается и сообщение показывается в окне аккаунтов. В режиме «Без VPN» сразу показывается открытие браузера.

Для режима **«С VPN»** добавьте собственную VPN-подписку в настройках приложения. Xray уже включён в архив; отдельно устанавливать Happ или Xray не нужно. Без VPN профили остаются отдельными, но используют обычное подключение компьютера.

## LegionAutoMiner

[LegionAutoMiner](https://github.com/Daniil0414/LegionAutoMiner) включён по умолчанию. Перед первым открытием игрового окна приложение само скачает и установит скрипт. **При каждом запуске окна скрипт обновляется с GitHub.**

Если GitHub временно недоступен, используется ранее сохранённая версия. Для самой первой загрузки нужен интернет. Добавление других скриптов и отключение выбранного доступны через кнопку **«Скрипт бота»**; ручное отключение сохраняется.

## Личные данные

Аккаунтов, cookies, VPN-ключей, подписок и профилей автора в архиве нет. Ваши данные создаются только при использовании программы:

- настройки и скрипты — в папке `app`;
- настройки VPN и журналы — в `app/.vpn_runtime`;
- авторизация отдельных профилей — в `%LOCALAPPDATA%\LegionMultiBot\Bots`.

Не передавайте эти данные вместе с программой. Встроенное обновление сохраняет личные настройки и профили.

Версии встроенных компонентов указаны в `app/COMPONENTS.json`, лицензии — в `app/licenses` и соответствующих папках компонентов.

Исходники, дополнительные запускатели и подробные инструкции по разработке: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Архив `legion-multibot.zip` в релизе предназначен для запуска из исходников; для обычной установки скачивайте `LegionMultiBot-windows.zip`.
