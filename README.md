# Legion MultiBot

Мультибот для Windows: несколько окон игры «Легион», отдельные профили Chrome, общая установка скриптов и управление VPN.

[Скачать установочный ZIP](https://github.com/Daniil0414/LegionMultiBot/releases/latest/download/LegionMultiBot-windows.zip) · [Релизы](https://github.com/Daniil0414/LegionMultiBot/releases)

## Что умеет

- Открывает игровые окна в сетке и управляет ими из одного приложения.
- Хранит авторизацию и настройки каждого профиля отдельно.
- Работает в режимах «С VPN» и «Без VPN».
- Включает [LegionAutoMiner](https://github.com/Daniil0414/LegionAutoMiner) по умолчанию и автоматически скачивает его перед первым открытием игрового окна.
- При каждом запуске окна заново получает актуальную версию скрипта с GitHub. При недоступности GitHub использует сохранённую копию.
- Поддерживает дополнительные скрипты из GitHub через главное приложение.

## Установка

Понадобятся Windows 10/11 и установленные:

1. [Google Chrome](https://www.google.com/chrome/).
2. [Python 3.10 или новее](https://www.python.org/downloads/windows/) с Tcl/Tk. При установке отметьте **Add Python to PATH**.
3. [Node.js](https://nodejs.org/en/download) — рекомендуется ветка LTS. Он нужен для обработки LegionAutoMiner.

Скачайте **LegionMultiBot-windows.zip** из [последнего релиза](https://github.com/Daniil0414/LegionMultiBot/releases/latest), распакуйте в отдельную папку и откройте **Запустить_Мультибот.bat**.

Установка через `pip install` или `npm install` не требуется. Chrome, Python, Node.js и Xray в архив не входят.

## Первый запуск

1. Выберите режим **«Без VPN»** или **«С VPN»**.
2. Создайте профили и выполните вход в свои игровые аккаунты в соответствующих окнах.
3. Откройте нужные окна из главного интерфейса.

**LegionAutoMiner уже включён:** вручную добавлять ссылку и нажимать установку не нужно. Для первой загрузки требуется доступ к GitHub. Если первая загрузка не удалась, игровое окно не откроется; следующий запуск повторит попытку. После успешной установки копия скрипта сохраняется на компьютере.

Через кнопку **«Скрипт бота»** можно обновить скрипт вручную, добавить другие скрипты или отключить выбранный. Ручное отключение сохраняется после перезапуска.

## VPN

В режиме **«Без VPN»** программа использует прямое подключение. Профили остаются отдельными, но внешний IP может быть общим.

Для режима **«С VPN»** нужен Xray. Можно положить `xray.exe` из [официальных релизов Xray-core](https://github.com/XTLS/Xray-core/releases) рядом с программой; также поддерживается ядро установленного Happ.

Откройте **«Настройки VPN» → «JSON серверов по ссылке подписки»**, вставьте свою ссылку и получите список серверов. Перед применением VPN-настроек закройте окна ботов. Программа проверяет доступность серверов и закрепляет маршруты за профилями; при отсутствии подходящего сервера запуск в режиме VPN блокируется.

## Как запускать

В папке программы один запускатель — **Запустить_Мультибот.bat**. Открывайте только его; остальные файлы загружаются приложением автоматически.

## Где хранятся ваши данные

Релиз содержит только основное приложение, его зависимости и эту инструкцию. VPN-настройки создаются программой автоматически. Аккаунты, cookies, авторизация, VPN-ключи и настройки автора в поставку не включены.

Ваши данные создаются локально при использовании:

- `accounts.json` — список аккаунтов приложения;
- `userscript_config.json` — установленные скрипты и их сохранённые версии;
- `.vpn_runtime/` — VPN-настройки, служебные файлы и журналы;
- `%LOCALAPPDATA%\LegionMultiBot\Bots` — отдельные профили Chrome и авторизация.

Не передавайте эти файлы вместе с программой. Обновления распаковывайте в отдельную папку; перенос личных настроек выполняйте локально. При чистой установке LegionAutoMiner включается автоматически, при обновлении сохраняются уже заданные настройки скриптов.

## Если не запускается

- Проверьте в терминале `python --version` и `node --version`.
- Если главное окно не появляется, запустите `python app_container.py` из папки программы, чтобы увидеть ошибку.
- Если LegionAutoMiner не загрузился впервые, проверьте доступ к GitHub и повторите запуск окна.
- Для запуска без VPN используйте основное приложение и выберите соответствующий режим.

Встроенный разбор JavaScript использует Acorn; лицензия находится в `vendor/acorn.LICENSE`.
