# LegionMultiBot v1.1.7 — исправление выбора VPN и проверки резервов

- При добавлении аккаунта VPN-серверы, закреплённые за другими профилями, пропускаются без сетевых проверок. Счётчик показывает оставшихся кандидатов, а сообщение об ошибке отдельно указывает число занятых серверов. Если весь пул занят, запуск останавливается сразу.
- Фоновая проверка резервного VPN больше не закрепляет его сервер и IP навсегда. Привязка записывается атомарно перед переключением аккаунта на этот маршрут. Если резерв успел занять другой профиль, трафик через него блокируется.
- После перезапуска приложение сначала пробует серверы, уже закреплённые за этим аккаунтом, прежде чем занимать новые.
- В выпуск включены все правки встроенного входа: большая область Chrome, встраивание окон авторизации, возврат того же браузера в сетку, блокировка повторного входа и отображение этапов подготовки.
- Сохранены все правки панели «Рой»: автоматическое появление, единая кнопка запуска/остановки шахты, последовательные команды с задержками 0, 1–5 и 1–10 секунд, ход рассылки и отмена ожидающих команд. Панель перемещается внутри сетки без шлейфа.
- Данные запуска из исходников и тестов отделены от проекта: настройки, VPN, журналы и браузерные профили разработки находятся в `%LOCALAPPDATA%\LegionMultiBot\Development`. Расположение данных portable-приложения сохранено.
- В исходники и сборку включены проверки, предотвращающие публикацию аккаунтов, VPN-ключей, профилей и других приватных данных.

Существующая история VPN-привязок сохраняется. Обновление не освобождает ранее закреплённые серверы/IP: если подходящего свободного выхода нет, для нового аккаунта потребуется отдельный рабочий VPN-сервер с другим внешним IP.

Для обновления перезапустите приложение и выберите «Обновить и перезапустить». Аккаунты, настройки, VPN-подписки и профили portable-приложения сохраняются.

Для ручной установки скачайте LegionMultiBot-windows.zip, закройте старую версию и распакуйте архив в её папку с заменой файлов программы. Запускайте Запустить_Мультибот.bat. Python, Chromium, Node.js и Xray включены.

Архив legion-multibot.zip содержит исходники; SHA256SUMS.txt — контрольные суммы обоих архивов.
