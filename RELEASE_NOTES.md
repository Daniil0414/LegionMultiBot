# LegionMultiBot v1.1.17 — мгновенный подхват живых VPN и защита от ложных сбоев

- **Мгновенный подхват живых серверов (Seamless Failover)**: устранена блокировка балансировщика нагрузки, которая не давала упавшим окнам сесть на проверенные рабочие серверы при массовом сбое пула. Теперь при любых сбоях провайдера аккаунты автоматически и беспрепятственно делят оставшиеся работающие каналы.
- **Единый глобальный кэш сбоев серверов (Shared Failure Cache)**: если один из серверов не отвечает по сети, информация о сбое мгновенно становится доступна всем окнам. Окна больше не тратят время на перебор заведомо недоступных адресов.
- **Устранение ложных срабатываний проверки**: таймаут проверочных сетевых запросов увеличен до 5.0 секунд, а порог допустимых сбоев фонового мониторинга поднят с 2 до 3. Это полностью исключило ложный сброс рабочих соединений («эффект домино») при сетевых всплесках во время одновременного запуска 40+ окон.
- **Двукратное расширение пула проверки маршрутов**: 8 параллельных воркеров для гладкой фоновой синхронизации интерфейса.
- **Мгновенный и надёжный запуск в шахту («Управление роем»)**: поддержка асинхронного старта ботов с надеванием шахтёрской каски (sync startBot) и защита от повторных кликов.

После обновления перезапустите приложение и окна ботов. Аккаунты, авторизация, настройки и VPN-подписки сохраняются.

Для обновления выберите «Обновить и перезапустить». Для ручной установки закройте старую версию и распакуйте LegionMultiBot-windows.zip в её папку с заменой файлов программы. Запускайте Запустить_Мультибот.bat. Python, Chromium, Node.js и Xray включены.

Архив legion-multibot.zip содержит исходники; SHA256SUMS.txt — контрольные суммы обоих архивов.
