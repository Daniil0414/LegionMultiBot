# LegionMultiBot v1.0.1

Упрощённая установка: один запускатель — **Запустить_Мультибот.bat**.

- Удалены дополнительные BAT-файлы, отдельный GUI, быстрый запуск и веб-менеджер вместе с их файлами.
- В установочном архиве оставлены только основное приложение, необходимые модули, обработка скриптов, Acorn с лицензией и инструкция.
- Личные настройки создаются автоматически; в архиве нет аккаунтов, cookies, VPN-подписок и профилей автора.
- LegionAutoMiner включён по умолчанию, устанавливается автоматически и обновляется с GitHub при каждом запуске окна.

Скачайте **LegionMultiBot-windows.zip**, распакуйте и запустите **Запустить_Мультибот.bat**. Требуются Google Chrome, Python 3.10+ с Tcl/Tk и Node.js.
