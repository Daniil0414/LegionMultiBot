# LegionMultiBot v1.1.5 — встроенная панель автошахты

- Управление роем встроено в окно мультибота. Панель перемещается и сворачивается вместе с приложением; её можно перетаскивать за заголовок в пределах сетки.
- Одна кнопка **«Запустить автошахту для всех»** переключается на **«Стоп»**. Команды работают во всех открытых управляемых окнах, включая другие страницы сетки.
- Исправлен шлейф при перетаскивании: освобождённые участки ячеек и встроенного Chrome корректно перерисовываются, в том числе при непрерывном движении мыши.
- Сохранены подтверждения команд и сообщения об ошибках по аккаунтам. При ошибке остановки кнопку «Стоп» можно нажать повторно.

Для обновления с v1.1.4 перезапустите приложение и выберите **«Обновить и перезапустить»**. Аккаунты, настройки, VPN-подписки и профили сохраняются.

Для ручной установки скачайте **LegionMultiBot-windows.zip**, закройте старую версию и полностью распакуйте архив в её папку с заменой файлов программы. Запускайте **Запустить_Мультибот.bat**. Python, Chromium, Node.js и Xray включены в сборку.

Архив **legion-multibot.zip** содержит исходники; **SHA256SUMS.txt** — контрольные суммы обоих архивов.
