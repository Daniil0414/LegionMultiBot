# LegionMultiBot v1.1.3 — обновления приложения и все текущие исправления

Для установки скачайте **LegionMultiBot-windows.zip**, полностью распакуйте и откройте **Запустить_Мультибот.bat**. Python, Chromium, Node.js и Xray уже включены; отдельно устанавливать их не нужно.

В этот выпуск включены все текущие изменения проекта:

- Проверка новых стабильных версий GitHub при запуске и окно «Обновить и перезапустить» / «Не обновлять». Прогресс и отмена скачивания, проверка SHA-256, перезапуск после завершения приложения, откат при ошибке. Аккаунты, настройки, VPN-подписки и профили сохраняются.
- Исправления завершения приложения и менеджеров: закрытие принадлежащих им браузеров, VPN-ядер и фоновых процессов, включая обработку ошибок очистки.
- Переключение VPN на проверенные резервные маршруты через локальный SOCKS-шлюз. При отсутствии рабочего VPN прямое соединение не используется. Проверены отказ сервера, резервные маршруты и передача DNS-имени через VPN.
- Обновления окон браузера: управление фокусом, размещение в сетке, навигация, отдельные профили и согласованные параметры обычного Chrome. Выбор «С VPN» / «Без VPN» сохраняется для текущего запуска.
- Автоматическая установка и обновление LegionAutoMiner, управление несколькими скриптами, отдельное хранение служебных настроек по профилям и origin.
- Исправления локального веб-менеджера, контроля доступа, запуска и завершения его процессов.
- Полная Windows-сборка со встроенными компонентами и отдельный архив исходников; проверка соответствия версии тегу релиза.

В v1.1.1 обновления самого приложения ещё нет: первый переход на v1.1.3 выполните вручную, закрыв старую версию и распаковав новый архив в ту же папку с заменой файлов программы. Последующие обновления будут предлагаться при запуске.

В архиве нет аккаунтов, cookies, VPN-ключей, подписок и профилей автора. Сборка проверяет Tk, окно обновления, встроенные Node.js/Xray/Chromium, локальную страницу и установку скрипта с ограниченным PATH. `SHA256SUMS.txt` содержит SHA-256 обоих архивов.
