# LegionMultiBot v1.1.9 — повторное использование VPN и правильный учёт занятости

- Сначала выбирается свободный рабочий VPN-сервер. Если свободных рабочих серверов нет, используется рабочий сервер с наименьшим числом других профилей. Повторное использование сервера и внешнего IP разрешено.
- Единая логика применяется при входе в аккаунт, запуске и работе игры, повторном подключении и резервном переключении, включая callbacks. Рабочий маршрут не меняется только из-за изменения нагрузки.
- Исправлена надпись «занято 81» при шести аккаунтах: исторические записи больше не считаются текущей занятостью и не исключают серверы из выбора. Учитывается только текущий сервер каждого подключённого профиля; общие серверы и IP разрешены.
- Старая история закреплений полностью исключена из новой логики и не изменяется. Проверки резервов и повторные проверки IP не увеличивают число профилей на сервере.
- Проверенные рабочие серверы рассматриваются раньше узлов, не прошедших последнюю проверку. Неисправный свободный узел не задерживает повторное использование рабочего; при отказе проверенных серверов перепроверяется остальной пул.
- При одновременном запуске нескольких аккаунтов нагрузка повторно проверяется под межпроцессной блокировкой. Готовый резерв, ставший более занятым, пересматривается перед переключением.
- Закрытие отдельного окна Chrome, программы, всех ботов и удаление аккаунта освобождают текущий счётчик. Неудачный запуск браузера также освобождает его. Записи завершившегося процесса не учитываются; PID проверяется вместе со временем создания, чтобы не спутать процессы.
- Разные локальные порты одного VPN-сервера не считаются отдельными серверами. При отказе всех VPN прямой интернет не подставляется.

После обновления перезапустите приложение и окна ботов. Аккаунты, авторизация, настройки и VPN-подписки сохраняются. Удалять историю привязок вручную не требуется.

Для обновления выберите «Обновить и перезапустить». Для ручной установки закройте старую версию и распакуйте LegionMultiBot-windows.zip в её папку с заменой файлов программы. Запускайте Запустить_Мультибот.bat. Python, Chromium, Node.js и Xray включены.

Архив legion-multibot.zip содержит исходники; SHA256SUMS.txt — контрольные суммы обоих архивов.
