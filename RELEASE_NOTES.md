# LegionMultiBot v1.1.13 — автоподхват окон роя и проверка статуса кнопки раз в минуту

- **Абсолютная устойчивость пульта («Управление роем»)**: устранена ошибка *«Версия скрипта не поддерживает управление автошахтой»*, возникшая из-за изменений в версиях LegionAutoMiner 9.1.41+.
- **Трёхуровневая архитектура защиты пульта**:
  1. *Умный парсер AST*: поддерживает любые составные условия переключения (`isPaused && !miningStartToken` и др.).
  2. *Универсальный DOM-контроллер*: если автор бота в будущем полностью изменит внутренний код функций, пульт автоматически переходит на прямой клик по кнопке `#b-btn` и отслеживание статуса `#b-st` в интерфейсе страницы.
  3. *Гарантия доступности в ядре*: лаунчер больше никогда не блокирует кнопку пульта для официального бота, гарантируя работу при любых будущих обновлениях скрипта.
- **Автоподхват роя (Auto-Swarm Watcher)**: когда рой запущен, лаунчер раз в минуту автоматически проверяет статус кнопки во всех окнах. Если окно перезагрузилось (сбой сети, ручной F5, восстановление слота) или вы открыли новое окно позже, лаунчер сам заметит статус паузы и автоматически запустит его в шахту с заданной задержкой, не сбивая уже копающие окна. В панель добавлен тумблер *«Проверять статус раз в минуту (автоподхват)»*.
- **Стабильность VPN-мониторинга**: интервал проверок фонового прокси скорректирован для предотвращения ложных сбросов соединений при кратковременных задержках сети.

После обновления перезапустите приложение и окна ботов. Аккаунты, авторизация, настройки и VPN-подписки сохраняются.

Для обновления выберите «Обновить и перезапустить». Для ручной установки закройте старую версию и распакуйте LegionMultiBot-windows.zip в её папку с заменой файлов программы. Запускайте Запустить_Мультибот.bat. Python, Chromium, Node.js и Xray включены.

Архив legion-multibot.zip содержит исходники; SHA256SUMS.txt — контрольные суммы обоих архивов.
