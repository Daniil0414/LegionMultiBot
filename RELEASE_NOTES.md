# LegionMultiBot v1.1.0 — готовый архив для Windows

Скачайте ZIP, полностью распакуйте и запустите **Запустить_Мультибот.bat**. Отдельная установка программ больше не требуется.

В архиве находятся приложение с Python/Tk, Chromium, Node.js и Xray. Используются собственные компоненты из папки `app`; системные установки не требуются.

LegionAutoMiner по умолчанию включён, устанавливается автоматически и обновляется с GitHub при каждом запуске окна. В архиве нет аккаунтов, cookies, VPN-подписок и профилей автора. Для VPN добавляется только собственная подписка пользователя.

Сборка проходит проверку с ограниченным PATH: запуск интерфейса Tk, встроенных Node.js/Xray/Chromium, открытие локальной страницы и установка скрипта с GitHub. `SHA256SUMS.txt` содержит контрольную сумму архива.
