# LegionMultiBot v1.1.10 — стабильность графики слотов и автоматическое восстановление окон

- Устранена причина исчезновения игровых окон из слотов: отключена экспериментальная подсистема рендеринга Chromium TreesInViz, вызывавшая падения GPU-процесса из-за расхождения координат областей перерисовки (crbug.com/454680865).
- Добавлен сторож и автоматическое восстановление слотов: при аварийном завершении любого окна браузера приложение автоматически обнаруживает потерю окна и повторно запускает и встраивает его в слот (с защитой от зацикливания до 3 попыток за 5 минут).
- Отключены нативные всплывающие окна автозаполнения форм, предотвращая падения PopupViewViews (код 0xC0000005) при встраивании окон через SetParent.
- Добавлено изолированное логирование сообщений об ошибках Chromium: stderr браузера сохраняется в chrome_stderr.log внутри папки профиля с ограничением размера до 5 МБ.
- Увеличена надёжность и скорость фильтрации VPN-серверов: таймаут проверки увеличен до 4.0 секунд, параллелизм расширен до 16 воркеров для быстрого отсева недоступных узлов.
- Улучшен алгоритм выбора серверов при добавлении новых профилей: свободный узел подбирается с приоритетом слота без лишних пересечений.

После обновления перезапустите приложение и окна ботов. Аккаунты, авторизация, настройки и VPN-подписки сохраняются.

Для обновления выберите «Обновить и перезапустить». Для ручной установки закройте старую версию и распакуйте LegionMultiBot-windows.zip в её папку с заменой файлов программы. Запускайте Запустить_Мультибот.bat. Python, Chromium, Node.js и Xray включены.

Архив legion-multibot.zip содержит исходники; SHA256SUMS.txt — контрольные суммы обоих архивов.
