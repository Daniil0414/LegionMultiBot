# LegionMultiBot v1.1.6 — вход внутри приложения и управление роем

- Chrome для входа открывается в большой встроенной области мультибота. Всплывающие окна авторизации также встраиваются в приложение. Кнопка «Вернуться к сетке» переносит тот же браузер в ячейку аккаунта, сохраняя профиль и авторизацию.
- После «Войти / Проверить» окно аккаунтов размывается и блокируется: показываются «Проверка VPN», текущий сервер и «Открытие браузера». Повторное нажатие не запускает второе окно. Список аккаунтов закрывается только после готовности встроенного браузера; при ошибке управление возвращается.
- Панель «Рой» появляется автоматически после открытия первого игрового окна.
- Одна кнопка «Запустить всех в шахту» переключается на «Стоп». Для старта и паузы доступны задержки 0, 1–5 и 1–10 секунд; по умолчанию — 1–5 секунд. Команды идут последовательно: первое окно сразу, перед каждым следующим выбирается новый случайный интервал.
- «Стоп» отменяет оставшиеся команды запуска и начинает рассылку паузы. Панель показывает ход рассылки и ошибки по аккаунтам.
- Подпись задержки размещена в две строки. Сохранены встроенное размещение панели, её перетаскивание в пределах сетки и исправление шлейфа.

Для обновления с v1.1.4 или v1.1.5 перезапустите приложение и выберите «Обновить и перезапустить». Аккаунты, настройки, VPN-подписки и профили сохраняются.

Для ручной установки скачайте LegionMultiBot-windows.zip, закройте старую версию и распакуйте архив в её папку с заменой файлов программы. Запускайте Запустить_Мультибот.bat. Python, Chromium, Node.js и Xray включены.

Архив legion-multibot.zip содержит исходники; SHA256SUMS.txt — контрольные суммы обоих архивов.
