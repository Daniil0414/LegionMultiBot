# LegionMultiBot v1.0.0

Первый публичный выпуск для Windows.

- Главное приложение с сеткой игровых окон и отдельными профилями Chrome.
- Работа с VPN и без VPN, локальный веб-менеджер и дополнительные запускатели.
- LegionAutoMiner включён по умолчанию, автоматически устанавливается перед первым открытием окна и обновляется с GitHub при каждом запуске окна.
- Сохранённая версия скрипта используется при недоступности GitHub после первой установки.
- В поставке отсутствуют аккаунты, cookies, токены, VPN-подписки и профили автора.

Скачайте **LegionMultiBot-windows.zip**, распакуйте и откройте **Запустить_Мультибот.bat**. Требуются Google Chrome, Python 3.10+ с Tcl/Tk и Node.js. Подробная инструкция находится в README.

`SHA256SUMS.txt` содержит контрольную сумму установочного архива.
